# Skidkalendern 2026/27

Statisk sida (ingen build). Tävlingarna ligger i `data.js` – redigera där.

## Publicera på GitHub Pages
1. Skapa ett repo och pusha innehållet i den här mappen till `main`.
2. Repo → Settings → Pages → Source: **GitHub Actions**.
3. Workflowen `.github/workflows/pages.yml` publicerar vid varje push.

## Lokalt
Öppna `index.html` i webbläsaren.

## Data
Datum kommer från Wikipedia och FasterSkier/ProXC (maj–nov 2026). Poster med `confirmed: false` har
motstridiga källor. Kontrollera mot IBU/FIS och uppdatera `data.js`.
